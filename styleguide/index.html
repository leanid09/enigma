Enigma design reference

Extracted from upakenigma.com (upakenigma.ru redirects there) on 11 November 2026. Every component below is rebuilt only from tokens/tokens.css, so this page is a check on the tokens.

Photos and icons are placeholders because the repository is public. Run scripts/fetch-assets.sh to download the originals into reference/, and the logo and icons will show up here. The live site uses the commercial font Museo Sans Cyrl. If it is not installed on your machine, Golos Text stands in, so letter widths will differ slightly.

Colour

Badges show the WCAG contrast ratio of white text (W) and black text (B) on each colour, calculated in your browser from the token. AA needs 4.5 for normal text and 3 for large text.

Typography

One family, Museo Sans Cyrl. Headings use weight 900 and body text 400, which renders the font's 500 file because of how the live site declares its faces. Sizes are fixed in pixels.
